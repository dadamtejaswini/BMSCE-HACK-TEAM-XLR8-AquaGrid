3. Tech Stack
•	Frontend: React, Tailwind CSS
•	Backend, Database & Auth: Supabase
________________________________________
4. Features Implemented
1.	Automated Booking System: Streamlined interface for users to request water tankers and schedule deliveries.
2.	Real-time Database: Integrated with Supabase to ensure live data synchronization and high availability.
3.	Smart Dashboard & Analytics: Visualized data insights for monitoring consumption patterns and distribution status.
4.	Robust Backend Architecture: Secure Node.js environment with modular routing and environment-safe configurations.
5.	User Management (Authentication): Secure sign-up/login flow to protect user data and booking history.

5. Installation Guide
Step 1: Clone the Repository
•	Open your terminal or command prompt.
•	Run the following command:
git clone(https://github.com/dadamtejaswini/BMSCE-HACK-TEAM-XLR8-AquaGrid)
•	Navigate into the project folder:
cd BMSCE-HACK-TEAM-XLR8-AquaGrid-main
Step 2: Install Backend Dependencies
•	Navigate to the server directory:
cd server
•	Install the required Node.js packages:
npm install
Step 3v : Install Frontend Dependencies
•	Navigate to the client directory:
cd ../client
•	Install the frontend packages:
npm install
________________________________________
6. How to Run Locally
Step 1: Start the Backend
•	In the /server folder, run:
npm start or node index.js
Step 2: Start the Frontend
•	In the /client folder, run:
npm run dev
Step 3: Verify Connection
•	Open your browser to: http://localhost:5173
•	Check the server terminal to ensure the Supabase client is initialized correctly and no "Configuration Errors" are present.
